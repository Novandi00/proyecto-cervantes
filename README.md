# Parcial: Adiviná el Número

Parcial de Introducción a la Programación — juego de adivinanza de números
desarrollado en Python.

## Integrantes
- Cáceres, Valentín
- Cardozo, Lautaro
- Soria, Javier

## Descripción
El programa genera un número secreto entre 1 y 100. El jugador dispone de
una cantidad de intentos configurables para adivinarlo, recibiendo pistas
("más alto" / "más bajo") en cada intento. Al finalizar se muestra un
resumen con el historial, puntaje y resultado.

## Cómo ejecutarlo
```bash
python parcial_adivina_numero_mejorado.py
